### Setting Up

1. Download and install xampp. And start the apache server and phpMyAdmin
2. download this repository to the xampp/htdocs folder.
3. open phpMyAdmin admin panel and go to phpMyAdmin inside it -> import -> choose file -> database.sql (the file in this repository) -> scroll bottom -> import
4. open your default browser and navigate to http://localhost/blossom

Done ✅
